# Elul Tekeste — Cybersecurity Portfolio

A personal portfolio for the Merit America cybersecurity program. Open index.html locally to preview.

## Publish on GitHub Pages
1. Sign in to GitHub and create a new public repository, e.g. `cybersecurity-portfolio`.
2. Upload `index.html` and optionally this README to the root of the repository and commit.
3. Open Settings > Pages. Under Build and deployment choose Deploy from a branch, select main and /(root), then Save.
4. Wait for the published URL to appear in Settings > Pages. Open it and check the content before submitting to Merit America.

The four project placeholders are intentionally marked Coming Soon. Update each corresponding article in index.html as coursework is completed.
